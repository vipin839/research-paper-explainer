# Research Paper Explainer

Paste a dense scientific abstract, choose a reading level, and get a plain-language
explanation generated by an **NVIDIA Nemotron** model through NVIDIA's hosted API.

Built for the NVIDIA GTC Berlin Golden Ticket Developer Contest.
**Inference-only** — no training, no fine-tuning.

---

## The problem

Students lose hours decoding jargon before they reach the actual finding of a paper.
Existing summarisers compress text but keep the vocabulary that caused the problem.
This tool rewrites an abstract at the reader's level and defines every unavoidable
term inline, so the reader learns the vocabulary instead of skipping it.

## Technical choices

| Choice | Why |
|---|---|
| `nvidia/nemotron-3-super-120b-a12b` | Verified fastest clean responder on the account (~2s to first token) |
| NVIDIA hosted API (`integrate.api.nvidia.com/v1`) | No GPU needed locally; OpenAI-compatible |
| `openai` Python client | The endpoint is OpenAI-API-compatible, so no custom HTTP code |
| Gradio | Minimal UI code, built-in streaming, optional public share link |
| `thinking: false` | Nemotron 3 is a reasoning model; left on it streams its private reasoning into the answer |
| Streaming + auto-retry | Text appears token-by-token; transient "server overloaded" errors are retried silently |

## Setup

```powershell
cd "F:\Claude Folder\gtc-paper-explainer"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Run

```powershell
$env:NVIDIA_API_KEY = "nvapi-your-key-here"
.\.venv\Scripts\python.exe app.py
```

Or use the launcher, which prompts for the key if it is not set:

```powershell
.\run.ps1
```

Add a public link (temporary `*.gradio.live` URL):

```powershell
.\run.ps1 -Share
```

The app opens at <http://127.0.0.1:7860>.

## Changing the model

Edit `MODEL_ID` at the top of `app.py`. Verified available on this account:

- `nvidia/nemotron-3-super-120b-a12b` (current)
- `nvidia/nemotron-3-ultra-550b-a55b`
- `mistralai/mistral-nemotron`

To list everything your key can reach:

```powershell
.\.venv\Scripts\python.exe -c "import os;from openai import OpenAI;print('\n'.join(sorted(m.id for m in OpenAI(base_url='https://integrate.api.nvidia.com/v1',api_key=os.environ['NVIDIA_API_KEY']).models.list().data)))"
```

## Accuracy note

The model is instructed to use only the pasted text and not to introduce outside
facts. It is a language model, so always check the explanation against the original
paper before relying on it.
